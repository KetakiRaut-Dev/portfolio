## ⚙️ Installation & Setup

### Clone repository

```bash id="c1x9aa"
git clone https://github.com/KetakiRaut-Dev/portfolio.git
```

### Move to project folder

```bash id="d2y8bb"
cd portfolio
```

### Install dependencies

```bash id="e3z7cc"
npm install
```

### Run locally

```bash id="f4a6dd"
npm start
```

### Build project

```bash id="g5b5ee"
npm run build
```

---

## 🚀 Deployment (GitHub Pages)

Install gh-pages:

```bash id="h6c4ff"
npm install gh-pages --save-dev
```

Add in `package.json`:

```json
"homepage": "https://ketakiraut-dev.github.io/portfolio"
```

Deploy:

```bash id="i7d3gg"
npm run deploy
```
